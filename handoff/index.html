導入流程

1
把 4 個檔案下載到專案 設計檔放專案的 handoff/ 資料夾，或開新 PR 直接上 main branch。
2
給 Claude Code 開工指令 打開 migration-notes.md 第 5 節「給 Claude Code 的開工提示詞」，整段複製貼上。
3
Phase A · 基礎建設（半天） Token、Tailwind、字體、兩個 layout 的 data-variant。
4
Phase B · 重構共用元件（1–2 天） 按推薦順序：Button → Badge → Input → Card → Table → Modal → Toast → EmptyState。每個元件都對照 component-recipes.html。
5
Phase C · Sprint 4 新功能套用 Token 與元件都到位後，新功能會自動帶上正確視覺。
提醒 Sprint 1–3 既有頁面不需要逐頁重做。共用元件改完，那些頁面自動換新衣。只有殘留的 hardcode 顏色（如 bg-gray-100）需要手動替換。
