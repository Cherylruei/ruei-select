給 Claude Code 的話

這 3 個頁面是 最終視覺，不是要直接複製 HTML。請參考
・佈局結構（哪些區塊、用什麼間距）
・欄位順序與資訊密度
・互動狀態（active filter、checked checkbox、hover）
・空狀態與引導
實作時，用 handoff/component-recipes.html 的 component class 組合，不要重複造輪子。
