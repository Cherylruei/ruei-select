02Buttons

主要動作用 primary + pill；次要用 secondary；第三層用 outline / ghost。所有 button 都有點擊縮放回饋。

Primary · 主要 CTA

下單、儲存、送出、新增。整頁同時不超過 1 個 primary。

{/* sm · md · lg · disabled */}
<button className="inline-flex items-center gap-2
  h-10 px-4.5 rounded-pill

  font-display font-semibold

07Order Status · 訂單狀態

PRD 訂單狀態機。商家後台、顧客前台共用同一套顏色配對 — 顏色就是狀態語言。

待採買 已訂購 已配單 已結單 已出貨 已完成 
{/* StatusBadge.tsx — 建議實作 */}
const STATUS_STYLE = {
  待採買: 'bg-warning-bg text-warning',
  已訂購: 'bg-info-bg text-info',
  已配單: 'bg-success-bg text-success',
  已結單: 'bg-sakura-100 text-sakura-700',
  已出貨: 'bg-earth-100 text-earth-700',
  已完成: 'bg-sunken text-fg-muted',
};

export function StatusBadge({ status }) {
  return (
    <span className={`inline-flex items-center gap-1
      h-6 px-2.5 rounded-pill
      font-display font-semibold text-xs
      ${STATUS_STYLE[status]}`}>
      <span className="w-1.5 h-1.5 rounded-pill bg-current" />
      {status}
    </span>
  );
}
